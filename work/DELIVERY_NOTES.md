# TOKYO TEARDOWN — iPhone 17 Enhanced 改修ノート

納品物: `TOKYO_TEARDOWN_iPhone17_Enhanced.html`（単一HTML、約415KB）。元ファイルは `work/original.html` に未改変で控えてあります。

## 実行条件
- 第一対象: iPhone 17 標準モデル / iOS Safari。縦持ち優先、横持ちでも配置を最適化（safe-area・Dynamic Island・ホームインジケーター対応）。
- 起動時に three.js 0.128.0 を CDN（cdnjs → jsDelivr → unpkg の順、すべて同一版）から読み込みます。失敗時は「再試行」ボタン。**完全オフラインでは動きません。**
- ファイルをそのまま Safari で開く（または任意の静的ホスティングに置く）だけで起動します。ビルド・npm・APIキー・有料素材は不要。
- URL に `?debug` を付けると検証フック `window.__tt` と、メニューの「性能表示」でフレーム時間分布（avg/p50/p95/worst）・処理区間・塊数・待ち行列・描画資源を確認できます。

## 既存機能（保持）と今回の改善の区別
保持: 3マップ（歌舞伎町／渋谷スクランブル／西新宿高層ビル街）と各ランドマーク、10武器、自由／60秒／3発モード、結果表示とベスト記録、直撃・倒壊・延焼・誘爆・巻き込みの評価、破壊球・戦術核のゼロ加点、反射・ブルーム・窓の室内表現・動的ライト・交通・歩行者・信号・延焼・連鎖・スローモーション・静的瓦礫・音・画質調整。

今回の改善（主なもの）:
1. 整合性: 耐久値配列を Uint16 に（620/260 が 108/4 に丸まる不整合を解消。生成・剥離・分割の全経路）。特異点が建物を剥がす条件（到達不能な予算値）と二重減算を修正。区画境界の面の再生成漏れを修正。再生成時の資源解放（塊配列の走査中 splice、路面テクスチャ、共有マテリアル、プールの返却）。核・破壊球のゼロ加点を迂回していた経路（車の撃破、ランドマーク補正、核起因の延焼・誘爆・ガス引火、終盤の掃討、転倒切断）を遮断。短い建物で NaN 座標に書き込んで live だけ増えていた生成バグを修正。
2. 時間: レールガン・軌道砲を固定刻みに、塊・粒子の減衰と毎フレーム確率を時間比例に、音の発音予算を時間基準に。実フレーム間隔（計測）／制限付きシミュレーション刻み／演出用の実時間／モードの時計（実経過時間。スロー・処理落ち・ポーズ・バックグラウンドで延びない）を分離。カメラは実時間で動く。
3. 画質: 段階設定（内部解像度の目標画素数・反射の更新間隔と解像度・ブルーム段数・MSAA・煙と人の上限）を一元管理。低→高で元の解像度に戻る。自動は3秒の傾向で下げ、12秒以上余裕が続けば1段戻す。反射描画は可視状態を try/finally で復元（元々非表示のものを表示しない）。
4. 中断・復帰: visibilitychange / pagehide でポーズ（音停止・入力解除）、復帰はメニューから。WebGL コンテキスト喪失時は覆いを出して復元を待ち、3秒で再読み込み（記録は保持）を提示。再生成時に飛翔中の弾・核・遅延リザルトが新しい街に漏れない（世代カウンタ）。
5. 見た目: マップごとの初期視点（歌舞伎町: 一番街アーチ越しにゴジラロードの奥／渋谷: 南の大通り上空から交差点へ／西新宿: 中央通りの南端から都庁方向）。空の光害ドームを狭く暗く、露出・ブルーム閾値を再調整。頂点属性 aM（素材＋損傷段階）で、コンクリートの型枠むら・タイルの目地・金属の継ぎ目・煉瓦の段と、損傷段階に応じたひび割れ・焦げ・骨材の露出を描画。killVoxel で隣接ボクセルを損傷段階1まで傷め、穴や切断面の周りに「割れた帯」を作る。巨大だったボクセル駐車車両（全長17m）を走行車と同じ実寸インスタンス（4.4m）に置換（爆風・落下塊で炎上）。濡れた路面の反射は距離で薄れ、地面は弱め。壊れた看板・窓の光が地面に残り続けないよう光の地図を2.5秒ごとに再構築。動く塊の模様・室内は局所座標で貼り付け（照明はワールド座標）。倒れた／大破した壁の看板文字は描かない。WebGL2 では看板の字形配列を直接参照（46回ループを撤去）。
6. 破壊の時間設計: 転倒は「軋み（音・足元の埃）→0.3〜0.55秒かけて傾き始める（描画メッシュを支点まわりに回転）→足元を断つ→上部が傾いた姿勢と回転の勢いを引き継いだ塊として倒れ込む→接触点の土煙と胴鳴り→瓦礫の余韻」。巨大な塊の分割で予算切れの破片を消さず元の塊に残して次フレームへ。剥離・メッシュ生成はセル数に加えて実行時間（5〜7ms）でも打ち切り。粉塵は主役を隠し切らない量・色に。
7. UI/入力: 上部に破壊率・スコア・モードの時間/残弾、下部中央に「現在＋直近2つ＋武器一覧」のクイックバー（任意の武器へ2タップ）、武器一覧シート（独自SVGアイコン・名前・説明・加点なしの印）、右上のメニュー（再開／音／振動／画質／演出の強弱／モード／マップ／同じ街で再挑戦／新しい街／性能表示／操作ヒント）。左下スティック（不感帯・外周で高速）、▲▼高度、右下 FIRE（押しながらドラッグで照準、112px）。カッターは FIRE からドラッグした角度と長さで照準を中心に切断線を描き、離して実行（画面ドラッグは視点のまま）。制御発破は設置数付きの起爆ボタン。指ごとの所有権を pointerId で管理し、pointercancel・キャプチャ喪失・メニュー表示・バックグラウンドでは攻撃確定せずに解除。照準の下に「何を狙っているか」（建物種別／ランドマーク名・素材・損傷率）と、「なぜ効いたか」（転倒・座屈・剥離・切断・窓の破砕）の短い表示。初回だけ操作ヒント。振動は Vibration API がある端末だけ有効（iOS Safari では「非対応」と表示。隠しスイッチや音による代替は廃止）。
8. 音: マスターにコンプレッサー、同時発音上限（30）と時間あたりの発音予算、距離減衰と左右定位（StereoPanner）。軋み・崩落の胴鳴り・瓦礫の余韻・素材別の破片音（ガラス／金属／木／コンクリート）を追加。ポーズで一時停止、ミュート・復帰を確実に。
9. 遊びの基盤: 街の seed を管理（「同じ街で再挑戦」と「新しい街を生成」を区別、メニューに表示）。損傷・誘爆・延焼の抽選はゲーム用乱数、粒子は装飾用乱数に分離。ベスト記録は採点仕様の版（v2）で別の鍵に保存し、旧記録は上書きしない。起動画面は街のメッシュが出来るまで残り（進捗バー連動）、見えていない街へ撃てる状態で始めない。

## 未検証・実機確認が必要な項目
- **iPhone 実機未検証。** 本作業環境には iPhone も GPU もなく、SwiftShader（CPU描画）での検証のため、60fps／30fps の達成は実測していません。目標値として段階設定を用意し、自動画質が実測フレーム間隔で調整します。
- iOS Safari 固有: AudioContext の復帰、StereoPanner、`visibilitychange` の挙動、Dynamic Island 周りの safe-area、WebGLMultisampleRenderTarget（WebGL2）の可否と自動フォールバック。
- 実機での描画負荷（看板シェーダー・反射・ブルーム）に対する段階設定の閾値（25ms で下げ、12秒余裕で戻す）の妥当性。
- 触感（iPhone では Vibration API 非対応のため「非対応」表示になります）。
